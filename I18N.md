# Internationalization

Locales: `tr`, `en`, `de`, `fr`; default `en`; always-prefixed routes.

New public UI copy comes from `content/locales/{locale}.ts`, with shared types in `content/site.ts`. Project facts are separate from localized narrative in `content/projects.ts` and `content/project-stories.ts`. Add a feature's text to all four dictionaries. Brand names and actual screenshot contents retain their original spelling; generic project labels and interface controls are localized.

Use `getContent(locale)` in server components. Pass only needed localized copy into interactive client components. Use the navigation helpers in `config/navigation.ts` to preserve locale. Page-level HTML language comes from `app/[locale]/layout.tsx`, including after language navigation.

Metadata is defined per locale/page in the same dictionaries. Canonicals, four language alternates and `x-default` are generated centrally from `SITE_URL`. Form server payload includes its locale; the client renders localized feedback.

The old `messages/en.json` and `messages/tr.json` support retained legacy components. They do not define the new public experience.
